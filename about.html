关于AI梦境档案馆

项目简介

AI梦境档案馆是一个全自动化的数字艺术项目，每天由AI创作一场独特的梦境，并以文字和图像的形式记录下来。这个项目展示了现代Web自动化技术的强大能力，实现了零运营成本的持续创作。

工作原理

  1. 每天自动从维基百科获取随机词汇作为创作种子
  2. 使用DeepSeek AI生成超现实的梦境描述文本
  3. 通过通义千问AI将文本转化为图像提示词
  4. 生成对应的梦境图像并保存
  5. 所有内容自动提交到GitHub仓库并发布

技术栈

  • 自动化工作流: GitHub Actions
  • 核心脚本: Python
  • AI服务: DeepSeek Chat, 通义千问
  • 前端技术: HTML, CSS, JavaScript
  • 数据存储: JSON文件 + Git版本控制
  • 网站托管: GitHub Pages
